# Changelog

All notable TittyTatter changes are recorded here.

The project follows semantic versioning from the initial development series onward.

## 0.0.1

Initial project baseline.

### Added

- TittyTatter project identity.
- Canonical root `VERSION`.
- Repository documentation structure under `docs/`.
- Defined 4/4 TI/TA rhythm model.
- Defined per-beat sixteenth/triplet subdivision.
- Defined independent TI, TA, and metronome audio semantics.
- Defined callback-driven timing architecture.
- Recorded the first working-prototype feature scope and feedback-driven roadmap.
